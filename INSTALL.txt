Live2Dマスコット連携わんコメプラグイン

必要なアプリ
・わんコメ（Windows）
・Live2D Desktop Mascot
  https://github.com/fixtan/live2d-desktop-mascot
  本プラグインはこのマスコットアプリへコメントを送る補助プラグインです。
  マスコットアプリ本体はこのZIPに含まれていません。

初回インストール
1. わんコメを終了してください。
2. ZIPを解凍してください。
3. 中の live2d-mascot-onecomme-plugin フォルダを、次の場所へコピーしてください。
   %APPDATA%\onecomme\plugins\
   エクスプローラーのアドレス欄に上のパスを入力すると開けます。
4. 次の構成になっていることを確認してください。
   %APPDATA%\onecomme\plugins\live2d-mascot-onecomme-plugin\plugin.js
   %APPDATA%\onecomme\plugins\live2d-mascot-onecomme-plugin\index.html
   フォルダを二重に入れないでください。node_modulesの配置は不要です。
5. Live2D Desktop Mascotを起動してください。
6. わんコメを起動し、プラグイン一覧で「Live2Dマスコット連携」を有効にしてください。

接続・読み上げ確認
1. わんコメからプラグインの設定画面を開いてください。
2. 「接続済み」になることを確認してください。
   接続完了時は「わんコメに接続しました。」と読み上げます。
   通常は %APPDATA%\Live2D Desktop Mascot\bridge.json を自動検出します。
   別の場所にある場合は「参照…」で選択してください。
3. 「テスト送信」を押し、マスコットがテスト文を読み上げるか確認してください。
4. 「コメントをマスコットへ送信する」にチェックしてください。
   初期状態ではコメント送信は無効です。
5. 設定は自動保存します。「自動保存済み」の表示を確認してください。
   名前・敬称・文字数上限・送信間隔・キューの設定も、この画面から変更できます。
6. 新着コメントで動作を確認してください。
   接続完了前の時刻を持つコメントは読み上げません。
   接続後の新着は初回から読みます。時刻不明の場合は初回だけ最後の1件を読みます。
   再接続時は基準時刻を更新し、それまでの送信待ちは破棄します。

更新インストール
変更内容は同梱の CHANGELOG.md を参照してください。
1. わんコメを終了してください。
2. 新しいZIPを解凍し、同じプラグインフォルダへファイルを上書きしてください。
3. 既存の settings.json は削除しないでください。保存した設定が入っています。
   ZIPには settings.json を含めていないため、配布ファイルの上書きで設定は置き換わりません。
4. わんコメを起動し、プラグインの接続を確認してください。

接続・保存に失敗した場合
・マスコットアプリが起動しているか、bridge.jsonの場所が正しいか確認してください。
・「接続・再接続」で再接続できます。切断後は自動でも再接続します。
・「詳細な状態」を開き、「状態を取得」で現在の状態を確認できます。
・設定保存に失敗した場合は入力内容を確認し、「保存を再試行」を押してください。
